# anveshak-owod-rs

Open-World Object Detector for remote sensing (Techfest IIT Bombay, "Anveshak").

> Stub - the full README with exact commands is written in phase 8.

Hard rules: random init only (no pretrained weights), no open-vocabulary / foundation
models, no network at train or inference time, test images are inference-only,
pure PyTorch + torchvision.
